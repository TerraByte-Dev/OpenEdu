One editable pane — no edit/preview toggle. Markdown renders at size while you type, and the syntax markers hide on every line except the one the cursor is on. The document underneath stays plain markdown, so the graph, tags, and retrieval index never see anything special.

Put the cursor on a line and its ##, **, ` and > come back so you can edit them. Leave, and they hide again. This is the whole trick behind "live preview" — one buffer, never two modes.

A missing link is dashed and faint, never red — it is a normal thing to write, not an error. Clicking one offers to create that note; nothing auto-creates, because a vault that spawns empty notes from typos stops being trustworthy.
