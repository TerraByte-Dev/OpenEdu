Mask Recolor

One monochrome PNG, painted in whatever the active accent happens to be. This is how the TerraByte mark survives eleven themes with zero per-theme assets — and it generalises to any single-colour shape you want to ship once and tint everywhere.

No sprite sheet, no eleven exports, no SVG fill to keep in sync. One 54 KB transparent PNG and a background colour.

Sizes and glow

Any size — it's a mask, so it scales to the box. --glow adds a drop-shadow in the accent. The last one overrides the fill to --ink-faint, which is how you get a de-emphasised mark without a second asset.

How

1

Export the shape as a transparent monochrome PNG. Only the alpha channel matters — the colour in the file is thrown away, so don't spend time on it. Square, generous padding, no baked-in glow.

2

Render an empty element. There is no <img> and nothing inside it; the element is a painted rectangle that the mask punches a hole through.

3

Set background-color to a token, and the mask to the file. Ship both -webkit-mask and mask.

4

Give it role="img" and an aria-label — an empty span is invisible to a screen reader otherwise.

.tb-logo {
  display: inline-block;
  flex-shrink: 0;
  background-color: var(--phosphor);          /* ← the only line that decides colour */
  -webkit-mask: url('logo.png') center / contain no-repeat;
          mask: url('logo.png') center / contain no-repeat;
}
.tb-logo--glow { filter: drop-shadow(0 0 5px var(--phosphor-faint)); }

<span class="tb-logo" role="img" aria-label="TerraByte Solutions"
      style="width:28px;height:28px"></span>

Worth knowing: the TerraByte brand doc says never recolour the mark outside the mint palette, and this deliberately breaks that rule — the mark takes the active theme accent instead. It is a considered exception, not an oversight. A single monochrome mask that adapts to every theme for free is worth more than colour orthodoxy, and the alternative is eleven exports that drift. If you reuse this recipe in another product, decide that trade explicitly rather than inheriting it.
