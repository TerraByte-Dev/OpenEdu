Interaction States

Five states, all expressed as border and glow shifts rather than fills. Two of these matter more than the rest: selected, because the app currently spells it five different ways, and focus, because the app has no focus indicator at all.

The five

staterecipe
defaultCalvin cycle--panel-lite, hairline rule
hoverCalvin cycle surface up one tier, text to --ink
selectedCalvin cycle veil fill + accent border + bright text
focusCalvin cycle 2px accent outline, 2px offset, 12px bloom
disabledCalvin cycle opacity .4, no hover, not-allowed

Focus ring

There are currently zero focus-visible rules in the app, which makes it effectively unusable by keyboard. That is not a polish item here — OpenEdu targets shared and donated school hardware where a dead or missing mouse is ordinary, and a lab machine driven by Tab is a normal way to use it.

Tab through these — the ring is live:

A link 
:focus-visible {
  outline: 2px solid var(--phosphor);
  outline-offset: 2px;
  box-shadow: 0 0 12px var(--phosphor-faint);
}

outline, not box-shadow alone: an outline survives an overflow:hidden ancestor and still renders in forced-colors mode, where box-shadows are dropped. The bloom is added on top so it reads as phosphor rather than as a browser default. :focus-visible rather than :focus, so it appears for keyboard users without ringing every mouse click.

Selected — one convention

Veil fill, accent left-border, bright text. One rule for rails, tabs, and choice cards alike.
