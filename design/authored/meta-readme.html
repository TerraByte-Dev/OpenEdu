OpenEdu Design System

The visual language of OpenEdu — an offline-first AI tutor built to run on shared, donated, low-spec school hardware. Every card here is a generation exemplar: whatever CSS a card contains is what gets learned as "what OpenEdu looks like", so cards are built from the app's real stylesheet rather than reimplemented.

Authoring rules

Tokens, never literals

Every colour is var(--phosphor), rgb(var(--phosphor-rgb) / 0.18), var(--ink-faint). No hex outside the :root preamble and the semantic-signal card. This is the highest-leverage rule in the system — it is the single thing that makes anything generated from these cards survive all eleven themes without extra work.

Use the real classes

Every card inlines the app's whole stylesheet, so .btn, .tag, .lcd, .cf-input, .window and .glow-line are all available and correct. Reach for those. A card that reimplements a button in its own CSS teaches a button that exists nowhere in the product. Author new CSS only where the app genuinely has no class for the thing.

Glow is the depth model

There are no drop shadows in OpenEdu. Elevation, focus, and emphasis are all expressed as phosphor bloom — box-shadow: 0 0 8px var(--phosphor-faint) and the .phosphor-glow family. A generated surface that reaches for a grey drop shadow will read as a different product immediately.

Brand: which blue is OpenEdu

Canonical — what ships

#00C6FF · #44D8FF · #6DD4EE · #000000

Lexend + IBM Plex Mono + Share Tech Mono. Used by the app, both logo lockups, every app icon, the website hero, and the share card.

Stale — never implemented

#0088ff · #4aadff · #80c8ff · #050810

The OpenEdu sub-brand block in the TerraByte brand doc. It has a zero-artifact footprint — no shipped surface has ever used it. Treat it as out of date, not as an alternative.

Two live blues would be worse than either one, so this is recorded as a stale spec rather than a divergence. Mint #00e5a0 is TerraByte corporate, not OpenEdu. Its one appearance in the product is the TerraByte globe in the About panel, and even there the CSS mask repaints it in the active theme accent — that recolour is a deliberate, documented exception to the brand doc's "never recolour the mark" rule, because a single monochrome mask adapting to eleven themes is worth more than colour orthodoxy.

Lexend is not a style choice. It was picked because its letterform spacing measurably improves reading speed and comprehension. The brand doc specifies Inter as the house face; that governs TerraByte's own marketing. Inter is TerraByte's voice, Lexend is OpenEdu's teaching surface, and for an app whose users read under bad conditions the teaching surface wins.
