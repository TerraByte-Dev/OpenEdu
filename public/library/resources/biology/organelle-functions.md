# Organelle Functions

The membrane-bound and other structures inside a **eukaryotic** cell. (Pairs with the animal vs. plant cell diagram.)

| Organelle | Function | Found in |
|---|---|---|
| Nucleus | holds DNA; controls the cell | both |
| Nucleolus | makes ribosomes | both |
| Ribosome | builds proteins | both |
| Rough ER | makes & transports proteins (has ribosomes) | both |
| Smooth ER | makes lipids; detoxifies | both |
| Golgi apparatus | packages & ships proteins | both |
| Mitochondrion | releases energy (ATP) via respiration | both |
| Chloroplast | photosynthesis (captures light) | plant only |
| Central vacuole | stores water; keeps turgor | large in plants |
| Lysosome | digests waste & worn parts | mainly animal |
| Cell membrane | controls what enters/leaves | both |
| Cell wall | rigid support & shape | plant only |
| Cytoplasm | jelly-like fluid holding organelles | both |

**Plant-only:** cell wall, chloroplasts, large central vacuole. **Mainly animal:** lysosomes, centrioles. Prokaryotes (bacteria) have **no** membrane-bound nucleus or organelles.
