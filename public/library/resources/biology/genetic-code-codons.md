# Genetic Code (Codon Table)

A **codon** is a group of three mRNA bases (A, U, G, C) that codes for one amino acid during translation. There are 4³ = **64 codons** for 20 amino acids, so the code is *redundant* (several codons can mean the same amino acid).

## The signals to memorize
- **START: AUG** — also codes for methionine (Met). Translation begins here.
- **STOP: UAA, UAG, UGA** — no amino acid; translation ends.

## A few common codons
- UUU / UUC → Phenylalanine (Phe)
- GGU / GGC / GGA / GGG → Glycine (Gly)
- GCU… → Alanine (Ala); GUU… → Valine (Val)
- AAA / AAG → Lysine (Lys); GAA / GAG → Glutamate (Glu)

## How to read the table (diagram)
The first base picks the row block, the **second base** picks the column, and the **third base** picks the sub-row. RNA uses **U (uracil)** wherever DNA would use T. Reading frame: codons are read in non-overlapping groups of three, 5'→3'.
