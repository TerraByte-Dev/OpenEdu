# Human Body Systems

The human body has **11 organ systems** that work together.

| System | Main organs | Primary function |
|---|---|---|
| Integumentary | skin, hair, nails | protection, temperature, sensation |
| Skeletal | bones, cartilage, joints | support, protection, makes blood cells |
| Muscular | skeletal/smooth/cardiac muscle | movement, posture, heat |
| Nervous | brain, spinal cord, nerves | senses and controls the body |
| Endocrine | glands (pituitary, thyroid, pancreas) | hormone signaling |
| Circulatory | heart, blood, vessels | transports O₂, nutrients, wastes |
| Respiratory | lungs, trachea, diaphragm | gas exchange (O₂ in, CO₂ out) |
| Digestive | stomach, intestines, liver | breaks down food, absorbs nutrients |
| Excretory/Urinary | kidneys, bladder, ureters | filters blood, removes waste |
| Lymphatic/Immune | lymph nodes, spleen, white cells | fights infection, fluid balance |
| Reproductive | ovaries/testes | produces offspring |

The nervous and endocrine systems **coordinate** the others; the circulatory system **connects** them all.
