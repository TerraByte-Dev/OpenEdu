# DNA / RNA Base Pairing

DNA is a **double helix**: two sugar–phosphate backbones joined by paired bases (the "rungs").

## Base pairs (complementary)
- **A pairs with T** (adenine–thymine) — 2 hydrogen bonds
- **G pairs with C** (guanine–cytosine) — 3 hydrogen bonds

So a strand reading A-T-G-C pairs with T-A-C-G on the other strand. (Memory aid: "**A**pple in a **T**ree, **G**arage by a **C**ar.")

## Purines vs pyrimidines
- **Purines** (two rings): Adenine, Guanine
- **Pyrimidines** (one ring): Cytosine, Thymine (and Uracil in RNA)
- A purine always pairs with a pyrimidine, keeping the helix an even width.

## DNA vs RNA
| | DNA | RNA |
|---|---|---|
| Strands | double | single |
| Sugar | deoxyribose | ribose |
| Bases | A, T, G, C | A, **U**, G, C |

In RNA, **uracil (U)** replaces thymine (T), so A pairs with U.
