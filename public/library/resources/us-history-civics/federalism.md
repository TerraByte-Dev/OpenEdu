# Federalism — Who Holds Which Powers

**Federalism** divides power between a **national (federal)** government and the **states**.

## Federal only (delegated/enumerated)
Coin and print money · declare war · raise and maintain armed forces · regulate **interstate and foreign commerce** · make treaties and foreign policy · run the postal system · set immigration/naturalization rules · admit new states.

## Shared (concurrent)
Tax · borrow money · build roads · establish courts · make and enforce laws · charter banks · take private property for public use (eminent domain).

## State only (reserved — 10th Amendment)
Run **public schools** · conduct **elections** · issue licenses (driver, marriage) · regulate **commerce within the state** · set up local governments · police powers (public health, safety, morals); marriage and divorce law.

## Key clauses
- **Supremacy Clause** (Art. VI) — federal law overrides conflicting state law.
- **10th Amendment** — powers not given to the U.S., nor denied to the states, are **reserved to the states or the people**.
