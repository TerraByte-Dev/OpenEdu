# Linear Equations & Slope

A line has a constant **slope** m = rise/run = (y₂ − y₁) / (x₂ − x₁).

## Forms of a line
- **Slope-intercept:** y = mx + b  (m = slope, b = y-intercept)
- **Point-slope:** y − y₁ = m(x − x₁)  (line through the point (x₁, y₁))
- **Standard:** Ax + By = C  (A, B, C integers, A ≥ 0)

## Slope facts
- Positive slope rises left→right; negative slope falls.
- Horizontal line: slope 0, equation y = b.
- Vertical line: slope undefined, equation x = a.
- **Parallel** lines have equal slopes.
- **Perpendicular** lines have negative-reciprocal slopes: m₁ · m₂ = −1.

## Example
Through (0, 1) with slope ½: y = ½x + 1. At x = 4, y = 3. In standard form that is x − 2y = −2.
