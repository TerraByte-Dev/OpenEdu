# Quadratic Reference

A quadratic is y = ax² + bx + c (a ≠ 0); its graph is a **parabola**.

## Quadratic formula
Solves ax² + bx + c = 0:

**x = ( −b ± √(b² − 4ac) ) / (2a)**

## Discriminant  D = b² − 4ac
- D > 0 → two real roots
- D = 0 → one repeated real root
- D < 0 → no real roots (two complex)

## Key features
- **Vertex** at x = −b/(2a); the axis of symmetry is x = −b/(2a).
- Opens **up** if a > 0 (has a minimum), **down** if a < 0 (maximum).
- **y-intercept** is c (set x = 0).
- **Vertex form:** y = a(x − h)² + k, with vertex (h, k).
- **Factored form:** y = a(x − r₁)(x − r₂), with roots r₁, r₂.
- Sum of roots = −b/a; product of roots = c/a.

**Example:** x² − 2x − 3 = 0 factors as (x − 3)(x + 1), so x = 3 or x = −1.
