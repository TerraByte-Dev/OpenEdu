# Laws of Exponents

For any base a ≠ 0 and integer (or rational) exponents m, n:

- **Product:** aᵐ · aⁿ = aᵐ⁺ⁿ  (add the exponents)
- **Quotient:** aᵐ ÷ aⁿ = aᵐ⁻ⁿ  (subtract the exponents)
- **Power of a power:** (aᵐ)ⁿ = aᵐⁿ  (multiply the exponents)
- **Power of a product:** (ab)ⁿ = aⁿ · bⁿ
- **Power of a quotient:** (a/b)ⁿ = aⁿ / bⁿ
- **Zero exponent:** a⁰ = 1
- **Negative exponent:** a⁻ⁿ = 1 / aⁿ
- **Fractional exponent:** a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ

## Worked examples
- 2³ · 2⁴ = 2⁷ = 128
- x⁵ / x² = x³
- (3²)³ = 3⁶ = 729
- 5⁻² = 1/25
- 8^(1/3) = ∛8 = 2

**Common mistake:** aᵐ · aⁿ is *not* aᵐⁿ — you ADD exponents when multiplying like bases. You only multiply exponents when a power is raised to another power.
