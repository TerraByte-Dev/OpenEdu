# Special Products & Factoring

**Multiplying — special products**
- **FOIL** (binomials): (a + b)(c + d) = ac + ad + bc + bd.
- **Difference of squares:** (a + b)(a − b) = a² − b².
- **Perfect-square trinomials:** (a + b)² = a² + 2ab + b²;  (a − b)² = a² − 2ab + b².

**Factoring — reverse the patterns**
1. **GCF first:** always pull out the greatest common factor. 6x² + 9x = 3x(2x + 3).
2. **Difference of squares:** a² − b² = (a + b)(a − b). x² − 25 = (x + 5)(x − 5).
3. **Perfect-square trinomial:** a² ± 2ab + b² = (a ± b)². x² + 6x + 9 = (x + 3)².
4. **Sum/difference of cubes:** a³ + b³ = (a + b)(a² − ab + b²);  a³ − b³ = (a − b)(a² + ab + b²).
5. **Trinomial x² + bx + c:** find two numbers that **multiply to c** and **add to b**. x² + 5x + 6 = (x + 2)(x + 3).

A sum of squares a² + b² does **not** factor over the real numbers. Check by multiplying back out.
