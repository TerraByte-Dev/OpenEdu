# Order of Operations & Properties

**Order of operations — PEMDAS** (a.k.a. GEMS / BODMAS). Work top-down; within a level, go **left to right**:

1. **P**arentheses / grouping symbols (also brackets, fraction bars, √).
2. **E**xponents and roots.
3. **M**ultiplication and **D**ivision — left to right (equal rank).
4. **A**ddition and **S**ubtraction — left to right (equal rank).

**Watch out:** ×/÷ share a level (do whichever comes first), and so do +/−. So 8 − 3 + 2 = 7, not 3.
**Example:** 2 + 3 × (4² − 6) = 2 + 3 × (16 − 6) = 2 + 3 × 10 = 2 + 30 = **32**.

**Properties of operations** (let a, b, c be any numbers):
- **Commutative:** a + b = b + a;  a × b = b × a (order doesn't matter).
- **Associative:** (a + b) + c = a + (b + c);  same for ×.
- **Distributive:** a(b + c) = ab + ac.
- **Identity:** a + 0 = a;  a × 1 = a.
- **Inverse:** a + (−a) = 0;  a × (1/a) = 1.
- **Zero product:** a × 0 = 0; if ab = 0 then a = 0 or b = 0.

Subtraction and division are **not** commutative or associative.
