# SI Units and Metric Prefixes

## The 7 SI base units
- Length — metre (m)
- Mass — kilogram (kg)
- Time — second (s)
- Electric current — ampere (A)
- Temperature — kelvin (K)
- Amount of substance — mole (mol)
- Luminous intensity — candela (cd)

## Metric prefixes (multiply the base unit)
- tera (T) = 10^12
- giga (G) = 10^9
- mega (M) = 10^6
- kilo (k) = 10^3
- hecto (h) = 10^2
- deca (da) = 10^1
- (base) = 10^0
- deci (d) = 10^-1
- centi (c) = 10^-2
- milli (m) = 10^-3
- micro (µ) = 10^-6
- nano (n) = 10^-9
- pico (p) = 10^-12

## Common derived units
- Force — newton (N) = kg·m/s²
- Energy — joule (J) = N·m
- Power — watt (W) = J/s
- Pressure — pascal (Pa) = N/m²
- Frequency — hertz (Hz) = 1/s
- Charge — coulomb (C) = A·s
- Voltage — volt (V) = J/C
- Resistance — ohm (Ω) = V/A

Convert by moving the decimal: each step on the prefix ladder is a factor of 10 (or 1000 between the big ones).
