# Logarithm Rules

A logarithm answers "to what power?": **logₐ x = y ⇔ aʸ = x** (with a > 0, a ≠ 1, x > 0).

- **Product:** logₐ(xy) = logₐ x + logₐ y
- **Quotient:** logₐ(x/y) = logₐ x − logₐ y
- **Power:** logₐ(xⁿ) = n · logₐ x
- **Change of base:** logₐ x = (ln x)/(ln a) = (log x)/(log a)
- **Identities:** logₐ 1 = 0,  logₐ a = 1,  logₐ(aˣ) = x,  a^(logₐ x) = x

## Notation
- **ln x** = logₑ x — the *natural log*, base e ≈ 2.718
- **log x** = log₁₀ x — the *common log*, base 10

## Examples
- log₂ 8 = 3 (because 2³ = 8)
- log 1000 = 3
- ln(e⁵) = 5
- log₂ 5 = ln 5 / ln 2 ≈ 2.32

Logs turn multiplication into addition — that is why they linearize exponential growth and underlie the decibel and pH scales.
