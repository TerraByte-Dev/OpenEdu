# Probability & Statistics

## Measures of center
- **Mean** x̄ = (Σx) / n — the average
- **Median** = the middle value when sorted (average the two middles if n is even)
- **Mode** = the most frequent value

## Measures of spread
- **Range** = max − min
- **Variance** σ² = Σ(x − μ)² / N
- **Standard deviation** σ = √(variance)

## Probability
- P(event) = favorable outcomes / total outcomes, with 0 ≤ P ≤ 1
- **Complement:** P(not A) = 1 − P(A)
- **Addition:** P(A or B) = P(A) + P(B) − P(A and B)
- **Multiplication (independent):** P(A and B) = P(A) · P(B)

## Counting
- **Permutations** (order matters): ₙPᵣ = n! / (n − r)!
- **Combinations** (order doesn't matter): ₙCᵣ = n! / (r!(n − r)!)

**Example:** a fair die has P(even) = 3/6 = ½. Rolling two dice, P(both 6) = 1/6 · 1/6 = 1/36.
