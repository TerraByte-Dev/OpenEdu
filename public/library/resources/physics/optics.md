# Optics — Reflection, Refraction & Lenses

Angles are measured from the **normal** (the line perpendicular to the surface).

- **Reflection:** angle of incidence = angle of reflection (θᵢ = θᵣ).
- **Refraction:** light bends when it changes speed crossing media.
  - **Snell's law:**  n₁·sin θ₁ = n₂·sin θ₂   (index n = c/v; see *Index of Refraction*)
  - It bends **toward** the normal entering a denser (higher-n) medium, and **away** when leaving.
  - **Only** going from denser → less-dense (n₁ > n₂): past the **critical angle** the light **totally internally reflects** (fiber optics).

## Lenses & mirrors
- **Converging:** convex lens / concave mirror — bends parallel rays to a focal point **F**.
- **Diverging:** concave lens / convex mirror — spreads rays apart.
- **Thin-lens / mirror equation:**  **1/f = 1/dₒ + 1/dᵢ**   (mirror focal length f = R/2)
- **Magnification:**  m = −dᵢ/dₒ = hᵢ/hₒ

## Image rules
- **Real image:** dᵢ > 0 — inverted, on the opposite side (object beyond F). Can be projected on a screen.
- **Virtual image:** dᵢ < 0 — upright, same side (object within F, or any diverging lens/mirror). Like a magnifying glass.
