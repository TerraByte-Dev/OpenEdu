# Ohm's Law & Circuits

Variables: V = voltage (volts, V), I = current (amperes, A), R = resistance (ohms, Ω).

- **Ohm's law:** V = I·R
- **Electric power:** P = V·I = I²·R = V²/R  (watts)
- **Charge:** Q = I·t  (coulombs)

## Combining resistors
- **Series** (one path): R_total = R₁ + R₂ + … — the same current flows through each; voltages add.
- **Parallel** (multiple paths): 1/R_total = 1/R₁ + 1/R₂ + … — the same voltage is across each; currents add. The total resistance is *less* than the smallest resistor.

## Example
A 12 V battery across a 4 Ω resistor drives I = V/R = 12/4 = 3 A and dissipates P = V·I = 12·3 = 36 W.
