# Mohs Hardness Scale

A relative scale of **scratch resistance**: a mineral can scratch anything softer (lower number) than itself. It is **ordinal**, not linear — diamond (10) is far harder than the gap from 9 to 10 suggests.

| # | Reference mineral |
|---|---|
| 1 | Talc (softest) |
| 2 | Gypsum |
| 3 | Calcite |
| 4 | Fluorite |
| 5 | Apatite |
| 6 | Orthoclase feldspar |
| 7 | Quartz |
| 8 | Topaz |
| 9 | Corundum (ruby, sapphire) |
| 10 | Diamond (hardest) |

**Field scratch tools:** fingernail ≈ 2.5, copper penny ≈ 3.5, steel knife / window glass ≈ 5.5, steel file ≈ 6.5. So quartz (7) scratches glass; calcite (3) does not.

Mnemonic: "**T**all **G**iraffes **C**an **F**ind **A**pples **O**r **Q**uietly **T**ake **C**old **D**rinks."
