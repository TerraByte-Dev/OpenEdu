# Ser vs Estar (the two Spanish "to be" verbs)

Both mean **"to be,"** but **ser** marks permanent identity while **estar** marks states, locations, and changeable conditions.

## Present indicative
| | ser | estar |
|---|---|---|
| yo | soy | estoy |
| tú | eres | estás |
| él/ella/usted | es | está |
| nosotros | somos | estamos |
| vosotros | sois | estáis |
| ellos/ellas/ustedes | son | están |

## Use SER for — mnemonic **DOCTOR**
- **D**escription (lasting traits): *Ella es alta.*
- **O**ccupation: *Soy profesor.*
- **C**haracteristic / personality: *Eres amable.*
- **T**ime, date, day: *Son las dos. Hoy es lunes.*
- **O**rigin / material: *Soy de México. Es de madera.*
- **R**elationship: *Es mi hermano.*

## Use ESTAR for — mnemonic **PLACE**
- **P**osition / **L**ocation: *Estoy en casa. Madrid está en España.*
- **A**ction (progressive, -ndo): *Estoy comiendo.*
- **C**ondition (temporary): *La sopa está caliente.*
- **E**motion / health: *Estoy cansado. ¿Cómo estás?*

**Meaning can shift:** *es aburrido* = he is boring (trait) vs *está aburrido* = he is bored (state). *Es listo* = clever vs *está listo* = ready.
