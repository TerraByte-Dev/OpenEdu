# Roman Numerals

## Symbols and values
- I = 1
- V = 5
- X = 10
- L = 50
- C = 100
- D = 500
- M = 1000

## 1 to 20
I (1), II (2), III (3), IV (4), V (5), VI (6), VII (7), VIII (8), IX (9), X (10), XI (11), XII (12), XIII (13), XIV (14), XV (15), XVI (16), XVII (17), XVIII (18), XIX (19), XX (20).

## Tens
X (10), XX (20), XXX (30), XL (40), L (50), LX (60), LXX (70), LXXX (80), XC (90), C (100).

## Hundreds
C (100), CC (200), CCC (300), CD (400), D (500), DC (600), DCC (700), DCCC (800), CM (900), M (1000).

## Rules
- Symbols are added left to right when larger or equal: VI = 5 + 1 = 6.
- A smaller symbol before a larger one is subtracted: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900.
- Don't repeat a symbol more than three times in a row.
- Examples: 2024 = MMXXIV, 49 = XLIX, 1999 = MCMXCIX, 444 = CDXLIV.
