# Map Symbols and Legend

Maps use a few standard tools so anyone can read them.

- **Legend (key)** — a box that explains what each color and symbol means.
- **Compass rose** — shows direction: the **cardinal** directions **N, E, S, W** and the **intermediate** ones (NE, SE, SW, NW). On most maps, up = north.
- **Scale** — relates map distance to real distance, as a **bar scale** or a ratio like **1:100,000** (1 unit on the map = 100,000 in the world).
- **Title** and a **grid** of latitude/longitude lines locate the area.

## Common symbols
- ★ in a circle = **capital city** · ● dot = **city/town**
- thick line = **highway/road** · line with crossties = **railroad**
- dashed line = **border/boundary** · wavy blue line = **river**; blue area = **lake/ocean**
- triangle = **mountain peak** · green = **forest/park**

Reading order: check the **title**, the **legend**, the **compass rose**, and the **scale** before measuring or navigating.
