# MLA Citation Format (9th edition)

MLA builds every Works Cited entry from **nine core elements**, in this order with this punctuation:

1. **Author.** 2. **"Title of source."** 3. **Title of container,** 4. Other contributors, 5. Version, 6. Number, 7. Publisher, 8. Publication date, 9. Location (page range / URL).

Use only the elements that apply. Entries have a **hanging indent**; the list is alphabetical by author's last name and titled **Works Cited**.

## In-text citation
- Pattern: **(Author Page)** — *no comma*: `(Smith 42)`.
- If the author is named in the sentence, give just the page: `Smith argues … (42).`
- No author → use a shortened **title**: `("Climate Report" 7)`.

## Works Cited templates
- **Book:** Last, First. *Title of Book*. Publisher, Year.
  *Morrison, Toni. Beloved. Knopf, 1987.*
- **Journal article:** Last, First. "Title of Article." *Journal Title*, vol. #, no. #, Year, pp. ##–##.
- **Web page:** Last, First. "Title of Page." *Title of Website*, Publisher, Day Month Year, URL.

Give the URL **without** "https://". Add an `Accessed Day Month Year.` note for sources with no date. Months are abbreviated except May, June, July.
