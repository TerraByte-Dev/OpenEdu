# Common Prefixes

A **prefix** is a word part added to the **front** of a root word to change its meaning. Knowing prefixes helps you decode unfamiliar words.

| Prefix | Meaning | Example |
|---|---|---|
| un- | not, opposite of | unhappy, undo |
| re- | again, back | redo, return |
| dis- | not, opposite of | disagree, disappear |
| in-/im-/il-/ir- | not | invisible, impossible, illegal, irregular |
| pre- | before | preview, prevent |
| mis- | wrong, badly | mistake, misspell |
| non- | not | nonfiction, nonstop |
| sub- | under, below | submarine, subway |
| inter- | between, among | interact, international |
| anti- | against | antifreeze, antibody |
| super- | above, beyond | superhero, supervise |
| trans- | across | transport, translate |
| over- | too much | overflow, overdo |
| under- | too little, beneath | underpaid, underground |
| semi- | half | semicircle |
| mid- | middle | midnight |
| bi- | two | bicycle |
| tri- | three | triangle |
| uni-/mono- | one | unicycle, monorail |
| auto- | self | automatic |

Same idea, the back of a word = a **suffix**; the core meaning unit = the **root**.
