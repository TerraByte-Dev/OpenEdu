# Common Suffixes

A **suffix** is a word part added to the **end** of a root. Suffixes often change a word's **part of speech** (e.g. *teach* → *teacher*).

## Inflectional (grammar) endings
| Suffix | Job | Example |
|---|---|---|
| -s / -es | plural noun / present verb | cats, wishes |
| -ed | past tense | walked |
| -ing | present participle / gerund | running |
| -er / -est | comparative / superlative | faster, fastest |

## Derivational (meaning) suffixes
| Suffix | Meaning → part of speech | Example |
|---|---|---|
| -ly | in a manner → adverb | quickly |
| -ness | state/quality → noun | kindness |
| -ment | action/result → noun | movement |
| -tion / -sion | act/state → noun | action, tension |
| -er / -or / -ist | one who → noun | teacher, actor, artist |
| -able / -ible | able to be → adjective | readable, visible |
| -ful | full of → adjective | hopeful |
| -less | without → adjective | hopeless |
| -ous | full of → adjective | dangerous |
| -ive | tending to → adjective | active |
| -al | relating to → adjective | natural |
| -y | characterized by → adjective | cloudy |

Spelling: drop a silent **e** before a vowel suffix (*make → making*); change **y → i** before most suffixes (*happy → happiness*); double a final consonant after a short vowel (*run → running*).
