# Commonly Confused Words

- **their / there / they're** — possessive / place / *they are*.
- **your / you're** — possessive / *you are*.
- **its / it's** — possessive / *it is* (or *it has*).
- **to / too / two** — toward / also-or-excessive / the number 2.
- **then / than** — time/next / comparison.
- **affect / effect** — usually verb (to influence) / usually noun (a result).
- **accept / except** — to receive / excluding.
- **lose / loose** — to misplace / not tight.
- **who's / whose** — *who is* / possessive.
- **principal / principle** — chief person/main / a rule or belief.
- **complement / compliment** — completes / praises.
- **stationary / stationery** — not moving / writing paper.
- **fewer / less** — countable items / uncountable amount.
- **i.e. / e.g.** — *that is* / *for example*.

Tip: if **it's** can be replaced by *it is*, use the apostrophe; otherwise use *its*.
