# Time Signatures

A time signature is two stacked numbers at the start of a staff that define the **meter** — how beats are grouped in each measure.

- **Top number** = how many beats are in each measure.
- **Bottom number** = which note value gets one beat: **2** = half note, **4** = quarter note, **8** = eighth note.

So **3/4** = three quarter-note beats per measure.

## Common meters
| Signature | Means | Feel |
|---|---|---|
| 4/4 (C) | 4 quarter-note beats | "common time"; most pop/rock |
| 3/4 | 3 quarter-note beats | waltz |
| 2/4 | 2 quarter-note beats | march, polka |
| 2/2 (¢) | 2 half-note beats | "cut time"; fast 2 |
| 6/8 | 6 eighth notes, felt in 2 | compound; lilting |

## Simple vs compound
- **Simple meter** (2/4, 3/4, 4/4): each beat divides into **2**.
- **Compound meter** (6/8, 9/8, 12/8): each beat divides into **3**; group eighths in threes (6/8 = two dotted-quarter beats).
- **C** = common time (4/4); **¢** = cut time (2/2).
