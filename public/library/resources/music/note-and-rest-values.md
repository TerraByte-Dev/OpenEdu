# Note & Rest Values

Each note's shape tells you how long to hold it; every note has a matching **rest** (silence) of the same length. Beats below are for **4/4** time (a quarter note = 1 beat).

| Note | Beats (in 4/4) | Rest |
|---|---|---|
| Whole note | 4 | whole rest |
| Half note | 2 | half rest |
| Quarter note | 1 | quarter rest |
| Eighth note | ½ | eighth rest |
| Sixteenth note | ¼ | sixteenth rest |

## How they relate
- Each value is **half** the one above it: 1 whole = 2 halves = 4 quarters = 8 eighths = 16 sixteenths.
- A **dot** after a note adds **half** its value: a dotted half = 2 + 1 = **3** beats.
- A **tie** joins two notes into one sustained sound (their values add).
- Eighth and shorter notes have **flags**, or are joined by a **beam** when grouped.

The bottom number of the time signature says which note gets one beat (4 = quarter, 8 = eighth, 2 = half), so beat counts change in other meters.
