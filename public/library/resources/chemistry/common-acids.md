# Common Acids & Their Formulas

| Acid | Formula |
|---|---|
| Hydrochloric | HCl |
| Sulfuric | H₂SO₄ |
| Nitric | HNO₃ |
| Phosphoric | H₃PO₄ |
| Acetic | CH₃COOH (HC₂H₃O₂) |
| Carbonic | H₂CO₃ |
| Hydrofluoric | HF |
| Hydrobromic | HBr |
| Hydroiodic | HI |
| Nitrous | HNO₂ |
| Sulfurous | H₂SO₃ |
| Hypochlorous | HClO |

**Naming rules** (an acid is H⁺ + an anion):
- Anion ends **-ide** → **hydro‑…‑ic** acid. Cl⁻ (chloride) → **hydro**chlor**ic** acid (HCl).
- Anion ends **-ate** → **‑ic** acid. SO₄²⁻ (sulfate) → sulfur**ic** acid (H₂SO₄).
- Anion ends **-ite** → **‑ous** acid. NO₂⁻ (nitrite) → nitr**ous** acid (HNO₂).

"-ate gives -ic, -ite gives -ous." Add enough H⁺ to balance the anion's charge.
