# Oxidation Number Rules

An oxidation number is the charge an atom *would* have if every bond were ionic. Apply the rules in **priority order** (higher rule wins a conflict):

1. A **free element** is **0** (Na, O₂, Cl₂, S₈ all = 0).
2. A **monatomic ion** equals its **charge** (Na⁺ = +1, S²⁻ = −2, Al³⁺ = +3).
3. **Group 1** metals = +1; **Group 2** = +2; **Fluorine** = always −1.
4. **Hydrogen** = +1 (but **−1** with a metal, e.g. NaH).
5. **Oxygen** = −2 (but **−1** in peroxides like H₂O₂; **+2** in OF₂).
6. The oxidation numbers in a **neutral compound sum to 0**; in a **polyatomic ion** they sum to the ion's charge.

**Worked example — find S in H₂SO₄:** H = +1 (×2 = +2), O = −2 (×4 = −8), total must be 0 → S = +6.

In **redox**: oxidation = increase in oxidation number (loses e⁻); reduction = decrease (gains e⁻). "**OIL RIG** — Oxidation Is Loss, Reduction Is Gain."
