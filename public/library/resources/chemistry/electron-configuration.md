# Electron Configuration & Shells

Electrons fill orbitals from lowest energy up (the **aufbau principle**).

## Filling order
1s → 2s → 2p → 3s → 3p → **4s → 3d** → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p → 7s

## Subshell capacities
- s holds 2 electrons (1 orbital)
- p holds 6 (3 orbitals)
- d holds 10 (5 orbitals)
- f holds 14 (7 orbitals)

A shell n holds up to **2n²** electrons (2, 8, 18, 32 …).

## Rules
- **Pauli:** max 2 electrons per orbital, with opposite spins.
- **Hund's:** fill each orbital in a subshell singly before pairing.

## Examples
- Oxygen (8): 1s² 2s² 2p⁴
- Sodium (11): 1s² 2s² 2p⁶ 3s¹ → [Ne] 3s¹
- Iron (26): [Ar] 4s² 3d⁶

**Valence electrons** (the outermost shell) drive bonding; for main-group elements they equal the group's ones digit.
