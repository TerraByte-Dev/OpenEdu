# Common Polyatomic Ions

Format: **name — formula — charge**.

## Positive (cation)
- Ammonium — NH4 — +1

## Charge -1
- Hydroxide — OH — -1
- Nitrate — NO3 — -1
- Nitrite — NO2 — -1
- Bicarbonate (hydrogen carbonate) — HCO3 — -1
- Acetate — C2H3O2 — -1
- Cyanide — CN — -1
- Permanganate — MnO4 — -1
- Hypochlorite — ClO — -1
- Chlorite — ClO2 — -1
- Chlorate — ClO3 — -1
- Perchlorate — ClO4 — -1

## Charge -2
- Carbonate — CO3 — -2
- Sulfate — SO4 — -2
- Sulfite — SO3 — -2
- Chromate — CrO4 — -2
- Dichromate — Cr2O7 — -2
- Peroxide — O2 — -2

## Charge -3
- Phosphate — PO4 — -3
- Phosphite — PO3 — -3

Pattern for oxyanions: "-ate" has one more oxygen than "-ite" (sulfate SO4 vs sulfite SO3); the charge stays the same across the set.
