# Color Wheel

The traditional artist's wheel (**RYB** model) arranges 12 hues in a circle to show how colors relate.

## The 12 hues
- **Primary** (can't be mixed from others): **red, yellow, blue.**
- **Secondary** (mix two primaries): **orange** (R+Y), **green** (Y+B), **violet/purple** (B+R).
- **Tertiary** (primary + neighboring secondary): red-orange, yellow-orange, yellow-green, blue-green, blue-violet, red-violet.

## Color relationships
- **Complementary** — opposite on the wheel; highest contrast: red↔green, yellow↔violet, blue↔orange.
- **Analogous** — next to each other (e.g. yellow, yellow-green, green); harmonious.
- **Triadic** — three evenly spaced (e.g. the three primaries).
- **Warm vs cool** — warm = red, orange, yellow (energy); cool = green, blue, violet (calm).

## Value & intensity
- **Tint** = hue + white (lighter); **shade** = hue + black (darker); **tone** = hue + gray.
- **Neutrals** (black, white, gray, brown) aren't on the wheel.

Note: mixing **light** uses a different (RGB) model — see the RGB vs CMYK card.
