# Color Models — RGB vs CMYK

Two ways color is made, depending on whether you are **adding light** or **subtracting it with ink**.

## RGB — additive (light: screens, TVs, phones)
- Primaries: **Red, Green, Blue.** Start from **black** (no light) and add light.
- R + G = **yellow** · G + B = **cyan** · R + B = **magenta**
- R + G + B = **white** (all light) · none = **black**.

## CMYK — subtractive (ink/pigment: printing)
- Primaries: **Cyan, Magenta, Yellow** (+ **K** = key/black). Start from **white** paper; ink subtracts light.
- C + M = **blue** · M + Y = **red** · C + Y = **green**
- C + M + Y ≈ a muddy black, so printers add real **black (K)** for depth and text.
- No ink = **white** (the paper).

## Why two models
Screens **emit** light (additive → RGB); print **reflects** light (subtractive → CMYK). RGB has a wider gamut, so bright screen colors can look duller once printed. The two sets of primaries are **complements** of each other.
