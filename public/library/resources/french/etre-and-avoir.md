# Être & Avoir (the two French auxiliaries)

**être** = "to be," **avoir** = "to have." They are the most common verbs and serve as **auxiliaries** for the passé composé (compound past).

## Present indicative
| | être (to be) | avoir (to have) |
|---|---|---|
| je | suis | ai (j'ai) |
| tu | es | as |
| il/elle/on | est | a |
| nous | sommes | avons |
| vous | êtes | avez |
| ils/elles | sont | ont |

## Where each is used
- **être** describes identity, state, profession, place: *Je suis étudiant. Nous sommes à Paris.*
- **avoir** shows possession and age: *J'ai un chien. Elle a quinze ans.*

## avoir idioms (English uses "to be")
- avoir faim / soif — to be hungry / thirsty
- avoir chaud / froid — to be hot / cold
- avoir … ans — to be … years old
- avoir raison / tort — to be right / wrong
- avoir peur / besoin de — to be afraid / to need

## Passé composé
Most verbs take **avoir** (*j'ai mangé*); a small set of motion/state verbs and all reflexives take **être** (*je suis allé·e*), and the participle then agrees with the subject.
