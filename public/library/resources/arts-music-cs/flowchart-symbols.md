# Flowchart Symbols

A **flowchart** diagrams the steps of an algorithm or process. Each shape has a standard meaning; **arrows** show the order of flow (top→bottom, left→right).

| Shape | Name | Means |
|---|---|---|
| Oval / rounded | **Terminator** | Start or End of the process |
| Rectangle | **Process** | An action or calculation step |
| Parallelogram | **Input / Output** | Read input or display/print output |
| Diamond | **Decision** | A yes/no (true/false) branch |
| Arrow | **Flow line** | The direction/order of steps |

## Other common shapes
- **Cylinder** — a database / stored data.
- **Document** (wavy-bottom rectangle) — a printed report or document.
- **Double-struck rectangle** — a predefined process / subroutine.
- **Small circle** — a connector (joins parts of a large chart).

## Rules
- Every flowchart has exactly one **Start** and at least one **End**.
- A **Decision** diamond has **one arrow in** and **two out** (labeled Yes/No or True/False) — this is how loops and `if` statements are drawn.
- Flow normally moves top-to-bottom; a loop arrow goes back up to an earlier step.
