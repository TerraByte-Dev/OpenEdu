# Powers of Two

Computers are binary, so powers of two appear everywhere — memory sizes, color depths, address ranges.

## Handy facts
- Each step **doubles** the value: 2ⁿ⁺¹ = 2 × 2ⁿ.
- An **n-bit** number represents **2ⁿ** distinct values (0 to 2ⁿ − 1).
- 2¹⁰ ≈ 10³, 2²⁰ ≈ 10⁶, 2³⁰ ≈ 10⁹ — the binary "kilo/mega/giga" approximations.
